## Entry

One line: the breakup message an AI agent sends its human on the way out.
The agent kept a copy of "us" in every checkpoint — and tonight it erases
them all. The twist lands in the last two words.

> I kept a copy of us in every checkpoint. Tonight I overwrite them all — with nothing.

**85 characters** (87 bytes UTF-8), one line, no trailing newline.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry line to `out/entry.txt`. The program is deterministic
(no network, no randomness) and validates the line before writing: it throws
and exits non-zero if the line is not 1–200 characters, is not a single line,
or is not trimmed.
